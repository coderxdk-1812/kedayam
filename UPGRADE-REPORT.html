🟢 What's New (built this session)

🪤 ClickFix / FakeCaptcha guard

The dominant 2024-2025 malware-delivery trick — and antivirus rarely catches it because the user runs the payload themselves.

  • Hooks clipboard.writeText & execCommand('copy') in the page's MAIN world
  • Classifies copied text for PowerShell / mshta / LOLBins / curl|bash / encoded commands
  • Reads on-page "press Win+R, paste, verify you're human" lures to corroborate
  • Hard blocking modal with a redacted preview — before the user can paste & run
lib/clipboardGuard.js · content/main-world-shim.js · content/content.js

📋 Freeware threat blocklist

Reputation protection that needs no Google/VirusTotal key and makes zero network calls by default.

  • Bundled offline seed of known phishing / malware hosts ships in the signed package
  • Local match on host and eTLD+1 → a blocklist hit forces a dangerous verdict
  • Opt-in refresh from FREE feeds (URLhaus, Phishing Army, OpenPhish) — only feed files fetched
  • 6-hour auto-update alarm + "Update now" button; browsing never leaves the device
lib/threatFeed.js · lib/rules/blocklistSeed.js · background.js

🔗 URL reputation intelligence

Catches modern spear-phishing URL tricks that pure look-alike matching misses.

  • Brand-in-subdomain spoof: paypal.com.account-verify.tk → dangerous when paired with sign-in
  • High-abuse / free TLDs (.tk .ml .ga .zip .xyz .top …) — escalate only with auth
  • URL-shortener awareness + account-lure path tokens (secure-update, verify-account)
  • Conservative weighting: a free-TLD blog stays Safe; a free-TLD login does not
lib/urlReputation.js · lib/trustEngine.js · lib/arbitration.js

⬇️ Malicious-download guard

Stops drive-by executable delivery from low-trust pages.

  • Intercepts clicks on .exe/.scr/.msi/.hta/.bat/.apk/.dmg/.ps1… links
  • Gated to near-zero FP: fires on low-trust pages or cross-origin executables only
  • Clear "this could run code on your device" modal with continue / trust options
content/content.js
